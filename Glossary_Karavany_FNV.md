# Глоссарий терминов предметной области «Управление караванными перевозками» (Fallout: New Vegas)

Документ содержит основные термины и сокращения, используемые в Vision и в описании системы.

| Термин | Определение |
| :---- | :---- |
| Пустошь  | территории, на которых осуществляются караванные перевозки - земли, подвергшиеся опустошению в результате Великой войны (ядерного апокалипсиса), с нарушенной инфраструктурой и наличием постоянных угроз (рейдеры, мутанты, радиация, враждебные фракции, конфликты между ними).  |
| Внешние системы | сторонние источники данных, с которыми взаимодействует ИС: радиооповещение об обстановке в Пустоши (в первую очередь радио New Vegas), контрольно-пропускные пункты НКР и других государств (или квази-государств) Пустоши. |
| Караван | Группа людей и брахминов (или транспорта), выполняющая перевозку груза между точками. |
| Рейс | Одна конкретная перевозка от отправителя до получателя по выбранному маршруту. |
| CaravanRequest | Карточка заявки на перевозку: груз, маршрут, команда, статусы, сроки. |
| Статус рейса | Состояние перевозки (например: подготовка, в пути, задержка, завершено). |
| Маршрут | Последовательность участков и контрольных точек, по которым движется караван. |
| Контрольная точка (Checkpoint) | Узел на маршруте (КПП, поселение, аванпост), где фиксируется прохождение. |
| CheckpointLog | Журнал отметок по контрольным точкам: время, результат, причины задержек. |
| ETA | Ожидаемое время прибытия (Estimated Time of Arrival). |
| Отклонение | Разница между планом (ETA/маршрут) и фактом (задержка, обход). |
| risk_score | Оценка риска рейса на основе условий маршрута, груза и текущей обстановки. |
| CargoManifest | Грузовой манифест: перечень позиций, упаковка, количество мест. |
| Пломба | Маркировка/замок на упаковке, подтверждающий целостность груза. |
| Расхождение | Несоответствие между манифестом и фактической выдачей/приёмкой. |
| SupplyReservation | Резерв припасов под рейс: вода, еда, боеприпасы, ремкомплекты, медприпасы. |
| Инцидент | Событие, влияющее на безопасность/груз/сроки (нападение, поломка, задержка). |
| Карточка инцидента | Запись об инциденте: тип, время, место, тяжесть, потери, последствия. |
| RecoveryRequest | Вторичная задача после инцидента: эвакуация, подмога, довоз, ремонт. |
| Спецгруз | Ценный/опасный груз (оружие, боеприпасы), требующий повышенного контроля. |
| Chain of custody | Цепочка передачи ответственности: кто и когда принял/передал спецгруз. |
| Audit trail | Журнал изменений: кто/когда/что изменил в заявке, манифесте или инциденте. |
| SLA | Соглашение по срокам/качеству доставки для клиента (Service Level Agreement). |
| Претензия | Запрос клиента по недостаче/повреждению/задержке с требованием фактов. |
| Ролевой доступ | Ограничение видимости и действий в системе по ролям пользователей. |
| Диспетчер караванов | Офисная роль: планирует рейсы, маршруты, назначает команду, контролирует статусы. |
| Караван-мастер | Полевой руководитель рейса: фиксирует движение, контрольные точки и события. |
| Кладовщик | Складская роль: формирует манифест, пломбы и резервы припасов. |
| Капитан охраны | Роль безопасности: определяет охрану и фиксирует угрозы/потери. |
| Полевой медик | Медицинская роль: ведёт медприпасы и медчасть инцидентов. |
| Полевой пользователь | Абстрактная роль, обобщающая участников рейса, работающих в полевых условиях через Pip-Boy: караван-мастера, капитана охраны и полевого медика. Используется в прецедентах, где все три роли совершают одно и то же действие (например, сообщение об инциденте). |
| Голотейп | Стандартный носитель данных Пустоши |
| Терминал (стационарный) | Стационарное рабочее место пользователя — персональный компьютер с монитором (разрешение не менее 1280×720), клавиатурой и манипулятором «мышь», подключённый к локальной сети организации, с установленным современным веб-браузером (Chrome, Firefox или аналог). Используется диспетчером, кладовщиком и суперпользователем для работы с веб-интерфейсом системы. |
| ПипБой (PipBoy) | Аналог смартфона в Пустоши |
| Организация |     Компания-клиент платформы (например, Crimson Caravan Company или Караваны Кэсседи), в рамках которой объединены пользователи, рейсы, заявки и связанные данные. Каждая организация изолирована от других: пользователи одной организации не имеют доступа к данным другой. |
| Суперпользователь | Административная роль уровня платформы. Суперпользователь создаёт организации, назначает первого диспетчера организации, управляет подписками и может выполнять любые действия в любой организации. Не является сотрудником караванной компании. Используется для расчета финансового отчета. |
| Ставка | Должностная ставка сотрудника в организации, определяющая его оплату. Назначается и редактируется диспетчером. |
| Ценность груза | Оценочная стоимость перевозимого груза (в крышках), указываемая диспетчером при создании заявки. Используется при расчёте risk_score: чем выше ценность, тем выше итоговый риск маршрута. |
| Статусная модель заявки | Набор состояний, через которые проходит заявка на перевозку в течение жизненного цикла:     - Draft (Черновик) — заявка создана, данные заполняются.     - Ready (Готов к отправке) — заявка укомплектована: команда назначена, манифест сформирован, припасы зарезервированы.     - En Route (В пути) — караван вышел на маршрут.     - Delayed (Задержка) — движение приостановлено (инцидент, проверка на КПП, погодные условия).     - Delivered (Доставлен) — груз доставлен в пункт назначения, караван-мастер подтвердил прибытие.     - Closed (Закрыт) — рейс завершён, манифест сверен, финансовый отчёт сформирован.     - Cancelled (Отменён) — рейс отменён до выхода каравана на маршрут. |
| Финансовый отчёт перевозки | Итоговый документ по рейсу, формируемый системой после доставки груза. Содержит: расходную часть (оплата охраны, медиков, припасы, пошлины на КПП, прочие затраты) и доходную часть (стоимость доставки по заявке). Разница между доходом и расходами составляет финансовый результат рейса. Отчёт формируется в крышках с указанием исходной валюты и курса конвертации. |

## Условные обозначения  
**ИС/Система** - Информационная Система “Караваны”
